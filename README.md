# ZERO TO BILLION

Jeu idle tycoon mobile : pars de 0 $ et construis un empire jusqu'au milliard.

**Jouer :** https://juleschampion03-maker.github.io/zero-to-billion/

- Tout le jeu tient dans `index.html` (aucune compilation).
- Comptes, amis et classement : Supabase (tables `ztb_` ; schéma de référence dans `supabase.sql`).
- Sur CrazyGames, le SDK de la plateforme prend le relais (pubs, sauvegarde) et le classement est masqué.
